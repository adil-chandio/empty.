# TABAHI — Next Level 3D Animation (Easy English)

## What this is
A premium 3D cinematic animation that runs in the browser. Every frame is designed to **hook, engage, and hypnotize** the viewer. Built with Three.js (WebGL) + Web Audio API. No external video or audio files — everything is generated by code.

**Theme:** *Controlled Chaos — Breaking creates beauty.*

## Camera Motions (Full Inventory)
- **Dolly in/out** — push toward subject / pull back for reveal
- **Orbit** — circle around characters / buildings
- **Pan** — horizontal scan across environment
- **Tilt** — vertical scan (up/down)
- **Roll (Dutch angle)** — tension, unease, imbalance
- **Zoom (FOV change)** — snap focus, emphasis
- **Camera shake** — impact, explosion, footsteps
- **Lens breathing** — subtle focus shift on dolly
- **Depth of field (Bokeh)** — foreground/background separation
- **Easing** — all moves use cubic-bezier for cinematic smoothness

## Audio Design (Eargasm / SFX)
All synthesized with Web Audio API (no MP3 files):

- **Ambient drone:** 20–200 Hz evolving noise bed
- **Impacts:** sub-thump (30–60 Hz sine) + broadband noise burst
- **Glass shatter:** high-passed noise + granular detuned ticks
- **Metal groan:** low saw wave + slow filter sweep
- **Riser/Swell:** rising saw + white noise filter sweep (anticipation)
- **Eargasm shimmer:** 10–14 kHz air band + chorus detune (physical pleasure)
- **Heartbeat kick:** 60 BPM sine thump
- **Synth stab:** square wave + fast envelope + reverb
- **Vocal "ahh":** non-lexical human texture
- **Spatial audio:** PannerNode for debris/camera-relative SFX

## Psychology Applied (Controls Viewer's Brain)
1. **Pattern interrupt** — symmetry breaks at 2.5s to re-orient attention.
2. **Mirror neurons** — facial expressions make viewers feel what characters feel.
3. **Anticipation → release** — risers before drops create dopamine payoff.
4. **Novelty / awe** — physics violations (folding buildings, zero-G).
5. **Closure** — reassembly resolves tension, satisfies the brain.
6. **Eargasm frequencies** — 10–14 kHz shimmer + sub-bass = physical pleasure.
7. **Hypnotic loop** — symmetrical start/end invites re-watch.

## How to Run

```bash
# 1. Install dependencies
npm install

# 2. Start live preview
npm run dev
# → opens live preview URL (Arena proxies it)
# → Click anywhere to unlock audio & begin
```

---

## Render a Real MP4 (Offline — needs Blender + FFmpeg on your machine)

```bash
blender -b -P blender_render.py
blender -b scene.blend -a
ffmpeg -framerate 60 -i frames/%04d.png -i audio.wav \
  -c:v libx264 -pix_fmt yuv420p -c:a aac -shortest tabahi.mp4
```

## Customize (Easy English)
- **Colors/theme:** edit `CONFIG.COLORS` in `js/app.js`

- **Audio:** `js/audio.js` — all synthesized; tweak frequencies/gain
- **Blender render:** `blender_render.py` mirrors the same story beats
